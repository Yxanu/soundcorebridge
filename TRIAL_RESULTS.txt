SoundcoreBridge / Liberty 5 listening-mode and EQ implementation
Date: 2026-10-31
Upstream: https://github.com/mervin008/soundcorebridge
Upstream revision: 3a631b9
Local branch: feature/liberty5-equalizer
Host: Apple Silicon, macOS 26.6.2, Swift 6.3.3

Device: Liberty 5 / A3957, firmware 03.90

Implemented
- Discover renamed Soundcore devices via the vendor SDP service.
- Connect on the actual vendor control channel (15 on the tested Liberty 5).
- Read Liberty 5 identity, firmware, left battery, and listening mode.
- Switch Noise Cancelling / Transparency / Normal from CLI and menu-bar app.
- Preserve the six non-mode bytes from the device's current sound settings.
- Confirm mode changes against a checksum-valid device state response.
- Reject stale or mismatched readback and expose errors in the menu-bar panel.
- All 22 EQ presets and custom eight-band EQ in CLI and menu-bar app.
- Use A3957's 114-byte two-channel EQ/HearID body, never Space 2's payload.
- Retain HearID calibration, hidden bands, timestamp, type and favorite genre.
- Select EQ with HearID disabled; explain that behavior in the app.
- Require both earbuds; block unverified Dolby/genre-HearID interaction.
- Keep ANC-strength controls disabled for Liberty 5.

Limits of this verification
- Firmware 03.90 omits the right EQ curve (ten FF bytes). Both curves are sent,
  but only available channel readback can be checked independently.
- These are control/state tests, not an acoustic measurement or listening test.
- Live tests started with HearID and Dolby/immersive audio disabled.
- Enabled initial/custom HearID restoration has synthetic offline coverage only.
- Genre-HearID and Dolby interaction remains blocked, not claimed as supported.

Build/run
./script/build_and_run.sh

Portable app
build/SoundcoreBridge-Liberty5.zip

On this Mac, File Provider adds FinderInfo to app directories under Documents
even in a .nosync folder. The run script therefore signs and launches a clean
temporary bundle and creates the ZIP from that same bundle. This is a local
ad-hoc build, not a notarized release.

Only listening-mode commands, EQ/HearID-preserving commands and state reads
were used for the functional tests. No calibration, button configuration,
spatial-audio setting or firmware-update operation was performed.
Raw identity packets, private device names and addresses are excluded from this
report and the tracked tests. Nothing was pushed to GitHub.
