SoundcoreBridge / Liberty 5 listening-mode implementation
Date: 2026-10-31
Upstream: https://github.com/mervin008/soundcorebridge
Upstream revision: 3a631b9
Local branch: feature/liberty5-sound-modes
Host: Apple Silicon, macOS 26.6.2, Swift 6.3.3

Device: Liberty 5 / A3957, firmware 03.90

Implemented
- Discover renamed Soundcore devices via the vendor SDP service.
- Connect on the actual vendor control channel (15 on the tested Liberty 5).
- Read Liberty 5 identity, firmware, left battery, and listening mode.
- Switch Noise Cancelling / Transparency / Normal from CLI and menu-bar app.
- Preserve the six non-mode bytes from the device's current sound settings.
- Confirm mode changes against a checksum-valid device state response.
- Reject stale or mismatched readback and expose errors in the menu-bar panel.
- Keep EQ and ANC-strength controls disabled for Liberty 5.

The live panel displays all three mode buttons. Its controller log confirms
Transparency, Normal and Noise Cancelling via device readback. The last
confirmed GUI state is Noise Cancelling, matching the original mode.

Checks

- Exact A3957 packet vectors cover all three modes.
- Tests verify preservation of unrelated settings, wrong-model rejection,

even in a .nosync folder. The run script therefore signs and launches a clean
temporary bundle and creates the ZIP from that same bundle. This is a local
ad-hoc build, not a notarized release.
